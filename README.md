
# Supply Chain Risk Forecasting

Forecasting potential delays in supply chains using weather disruption data.

## Tech Stack
- Python
- Pandas
- Time-Series Analysis
- Matplotlib

## Features
- Analyze historical weather + logistics data
- Identify disruption zones
- Forecast potential delays for BOM/part delivery

## Dataset
- NOAA Climate Data (can be added)
- Supply route mock data

## Output
- Delay heatmaps
- Risk prediction graphs
